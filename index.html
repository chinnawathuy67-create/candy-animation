ความไวในการเอียง 3D (Tilt Sensitivity): 18°
จำนวนละอองประกาย (Particle Count): 120 เม็ด

สถาปัตยกรรม JavaScript Animation ในโปรเจกต์นี้ผสาน 5 เทคนิคหลักเข้าด้วยกัน:

1. 3D Parallax & Lerp Damping ▼

ใช้สมการเชิงอนุพันธ์ current += (target - current) * 0.08 เพื่อให้มุมหมุน rotateX และ rotateY ตอบสนองต่อเคอร์เซอร์อย่างนุ่มนวลเหมือนวัตถุมีน้ำหนัก

2. Dynamic Holographic Foil Specular ▼

คำนวณเวกเตอร์แสง (lightX, lightY) บน Canvas 2D ด้วย createRadialGradient และ blend mode screen เพื่อจำลองแสงเงาตกกระทบบนซองฟอยล์เมทัลลิก

3. Canvas Particle Engine & Bokeh ▼

ระบบอนุภาค 60 FPS จัดการ Bokeh สีทอง, ฟองก๊าซซ่าของโคล่า, ละอองผลไม้เบอร์รี่, และดาวประกาย 4 แฉก (drawSparkle)

4. Web Audio API Synthesizer ▼

สังเคราะห์เสียง Pop ลูกอม, เสียง Fizz ซ่า, และเสียงประกายระยิบระยับด้วย Oscillator (sine, triangle) โดยไม่ต้องพึ่งพาไฟล์เสียงภายนอก

🥤 ซองสีดำ: รสโคล่า (Sparkling Cola)

หอมหวาน รสโคล่าซ่าเข้มข้น ผสานความเย็นสดชื่น เคี้ยวเพลินหนึบหนับ ให้พลังงานและความสดชื่นตลอดวัน

🍇 ซองสีม่วง: รสเบอร์รี่ (Juicy Berry)

กลิ่นหอมของเบอร์รี่รวมฉ่ำใจ เปรี้ยวอมหวานลงตัว คัดสรรความอร่อย คุณภาพระดับพรีเมียม
